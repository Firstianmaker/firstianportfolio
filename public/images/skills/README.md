# Skill icon attribution

Local copies keep portfolio icons independent of third-party image requests at runtime.

- Skill Icons: https://github.com/tandpfun/skill-icons, fetched from https://skillicons.dev on 2026-09-30. License: skill-icons-LICENSE.txt.
